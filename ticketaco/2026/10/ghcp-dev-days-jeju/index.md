# Dev Days | Jeju, South Korea

![GitHub Copilot Dev Days Jeju](https://devrel-kr.github.io/event-landing-page/ticketaco/2026/10/ghcp-dev-days-jeju/images/hero.jpg)

GitHub Copilot app과 GitHub Copilot CLI를 깊이 있게 살펴보는 실전 워크샵입니다.

- **일시:** 2026년 10월 31일 (토) 12:00 - 18:00
- **장소:** 제주창조경제혁신센터
- **주소:** 제주특별자치도 제주시 중앙로 217, 제주벤처마루 3층
- **참가 대상:** 학생, 개발자, AI 코딩에 관심 있는 누구나

---

## 이런 분들을 위한 행사입니다

### AI 코딩을 처음 시작하는 분

GitHub Copilot app과 CLI의 기본 개념부터 실제 개발 흐름에 적용하는 방법까지 차근차근 경험합니다.

### 업무 효율을 높이고 싶은 분

AI 보조 개발의 최신 기능과 활용 패턴을 통해 일하는 방식을 한 단계 발전시킵니다.

### 커뮤니티와 연결되고 싶은 분

제주의 개발자 및 비개발자와 경험을 나누고 함께 배우는 시간을 만듭니다.
