# Dev Days | Seoul, South Korea

![GitHub Copilot Dev Days Seoul](https://devrel-kr.github.io/event-landing-page/ticketaco/2026/10/ghcp-dev-days-seoul/images/hero.jpg?v=2)

GitHub Copilot app과 GitHub Copilot CLI를 깊이 있게 살펴보는 실전 워크샵입니다.

- **일시:** 2026년 10월 24일 (토) 12:00 - 18:00
- **장소:** 한국 마이크로소프트 13층
- **주소:** 서울특별시 종로구 종로1길 50, 더케이트윈타워 A동
- **참가 대상:** 학생, 개발자, AI 코딩에 관심 있는 누구나

---

## 이런 분들을 위한 행사입니다

### AI 코딩을 처음 시작하는 분

GitHub Copilot app과 CLI의 기본 개념부터 실제 개발 흐름에 적용하는 방법까지 차근차근 경험합니다.

### 업무 효율을 높이고 싶은 분

AI 보조 개발의 최신 기능과 활용 패턴을 통해 일하는 방식을 한 단계 발전시킵니다.

### 커뮤니티와 연결되고 싶은 분

서울의 개발자 및 비개발자와 경험을 나누고 함께 배우는 시간을 만듭니다.

---

## 키노트

### 비개발자가 GitHub Copilot으로 코드가 아닌 '진짜 문제'를 푸는 실전 AX

![이영빈](https://devrel-kr.github.io/event-landing-page/ticketaco/2026/10/ghcp-dev-days-seoul/images/speaker-youngbin-lee-thumb.jpg?v=2)

**이영빈**  
전략개발팀장 · GM TCK

전통적인 제조업 현장인 자동차 엔지니어링 연구소에서 AI 혁신을 이끌고 있습니다. 비개발자의 시선으로 GitHub Copilot과 AI 에이전트를 도입하고, 조직 내 자생적인 러닝 루프를 설계하며 부딪히고 확장해 나갑니다. 결코 만만치 않은 조직의 AX. 하지만 진짜 문제를 쥔 도메인 전문가들이 소프트웨어로 답을 찾아가는 그 치열한 과정을 함께 만들어가고 있습니다.

[GitHub](https://github.com/binnu-dev) · [LinkedIn](https://www.linkedin.com/in/youngbinlee)

![김진석](https://devrel-kr.github.io/event-landing-page/ticketaco/2026/10/ghcp-dev-days-seoul/images/speaker-jinseok-kim-thumb.jpg?v=2)

Microsoft MVP · KH시스템즈

.NET 분야에서 Microsoft MVP로 활동하고 있으며, 서로 다른 분야를 연결해 시너지를 만드는 일을 좋아합니다. 요즘은 GitHub에 관심을 갖고 들여다보고 있습니다. 저는 완전 I형 인간이라 낯가림은 있어도 대화는 환영이니, 편하게 말 걸어주세요.

![방은지](https://devrel-kr.github.io/event-landing-page/ticketaco/2026/10/ghcp-dev-days-seoul/images/speaker-eunji-bang-thumb.jpg?v=2)

**방은지**  
KH시스템즈

KHSystems에서 개발자로 근무하며 GitHub와 GitHub Copilot을 활용한 AI 기반 개발에 관심을 가지고 있습니다. 최근에는 AI와 MCP를 활용한 개발 사례를 주제로 발표하고, GitHub Copilot 워크숍에 프록터로 참여하는 등 다양한 경험을 쌓고 있습니다. 꾸준히 배우고 직접 경험한 내용을 공유하며, GitHub 생태계에서 함께 성장하고 도움을 줄 수 있는 개발자가 되는 것을 목표로 하고 있습니다.

[LinkedIn](https://www.linkedin.com/in/%EC%9D%80%EC%A7%80-%EB%B0%A9-10b220356/)
