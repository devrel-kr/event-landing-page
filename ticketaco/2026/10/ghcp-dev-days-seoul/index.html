Keynote

비개발자가 GitHub Copilot으로 코드가 아닌 '진짜 문제'를 푸는 실전 AX

이영빈

전략개발팀장 · GM TCK

전통적인 제조업 현장인 자동차 엔지니어링 연구소에서 AI 혁신을 이끌고 있습니다. 비개발자의 시선으로 GitHub Copilot과 AI 에이전트를 도입하고, 조직 내 자생적인 러닝 루프를 설계하며 부딪히고 확장해 나갑니다. 결코 만만치 않은 조직의 AX. 하지만 진짜 문제를 쥔 도메인 전문가들이 소프트웨어로 답을 찾아가는 그 치열한 과정을 함께 만들어가고 있습니다.

연사 소개

트랙별 워크샵을 함께 이끌 연사들을 소개합니다.

트랙 A

김진석

Microsoft MVP · KH시스템즈

.NET 분야에서 Microsoft MVP로 활동하고 있으며, 서로 다른 분야를 연결해 시너지를 만드는 일을 좋아합니다. 요즘은 GitHub에 관심을 갖고 들여다보고 있습니다. 저는 완전 I형 인간이라 낯가림은 있어도 대화는 환영이니, 편하게 말 걸어주세요.

트랙 A

방은지

KH시스템즈

KHSystems에서 개발자로 근무하며 GitHub와 GitHub Copilot을 활용한 AI 기반 개발에 관심을 가지고 있습니다. 최근에는 AI와 MCP를 활용한 개발 사례를 주제로 발표하고, GitHub Copilot 워크숍에 프록터로 참여하는 등 다양한 경험을 쌓고 있습니다. 꾸준히 배우고 직접 경험한 내용을 공유하며, GitHub 생태계에서 함께 성장하고 도움을 줄 수 있는 개발자가 되는 것을 목표로 하고 있습니다.

트랙 B

김영대

Microsoft MVP

Azure MVP 이자 MCT로 페이스북 슬기로운 Azure 생활 커뮤니티 운영자로 활동 하고 있습니다. Microsoft의 전문 MSP 회사에서 Azure/M365을 토대로 AI 및 보안 등 클라우드 기술 전반을 리딩하며 돈도 벌고 있습니다. 부단한 자기계발과 더불어 성장, 그리고 사람들의 성공을 돕는 일을 가치로 삼고 있습니다.

트랙 B

유저스틴

수석 디벨로퍼 아드보캇 · Microsoft/GitHub

Microsoft와 GitHub에서 수석 디벨로퍼 아드보캇으로 활동하며 개발자 커뮤니티와 다양한 채널을 통해 소통하고 있습니다. 자나깨나 개발자 생산성 향상에 Azure, .NET, GitHub Copilot 등이 어떻게 도움이 될 수 있을까 고민합니다.
