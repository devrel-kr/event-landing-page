## 에이전트 성능, 한 걸음씩 더 나아지도록.

에이전트를 만드는 것에서 한 걸음 더 나아가, 성능을 어떻게 개선할 수 있을지 직접 실습하는 핸즈온 워크샵입니다.

**Hill Climbing(힐 클라이밍)** 방식으로 작은 개선을 반복하며 에이전트 성능을 점진적으로 높이는 **Continuous Improvement(점진적 개선)**를 경험합니다. Microsoft Foundry와 GitHub Copilot을 활용해 개선 전후의 결과를 비교하고, 다음 개선 방향을 찾아봅니다.

WHO IT'S FOR

## 이런 분들을 위한 행사입니다

### 에이전트 성능을 개선하고 싶은 분

만들어 둔 에이전트의 결과를 살펴보고, 더 나은 성능을 위한 개선 방법을 직접 경험하고 싶은 분을 위한 워크샵입니다.

### 점진적 개선을 실습하고 싶은 분

Hill Climbing(힐 클라이밍) 방식으로 작은 변화를 적용하고 결과를 비교하며, 개선을 반복하는 과정을 배우고 싶은 분께 추천합니다.

### Microsoft Foundry와 GitHub Copilot을 활용하고 싶은 분

두 도구를 활용해 에이전트 최적화를 직접 실습해 보고 싶은 분을 환영합니다.

## 참가자 준비물 및 주의사항

- 핸즈온 실습을 위해 랩탑을 준비해 주세요.
- 실습에 사용할 Azure 구독은 각자 준비해 주세요.
- Azure 구독이 없다면 [무료 구독 만들기](https://aka.ms/azure/free)를 통해 준비할 수 있습니다.
- GitHub Copilot 실습용 라이센스는 행사 당일 참석자를 대상으로 제공됩니다.
- GitHub Copilot 라이센스 구독 이력이 있거나 현재 구독 중인 계정을 사용하면 문제가 생길 수 있습니다. 해당하는 경우 새 GitHub 계정을 만들어 와 주세요.
- Azure 실습 중 리소스 및 모델 사용량에 따라 비용이 발생할 수 있습니다. 개인 구독의 크레딧과 예산을 미리 확인해 주세요.
- 실습이 끝나면 사용한 Azure 리소스를 확인하고, 더 이상 필요하지 않은 리소스는 삭제해 추가 비용을 방지해 주세요.

## 함께 실습하고, 경험을 나누는 자리

도구 소개에 머물지 않고, 직접 만들고 개선하는 실습 중심의 배움을 지향합니다. AI 개발 도구로 아이디어를 실제 앱으로 만드는 경험에서 한 걸음 더 나아가, 이번에는 에이전트의 성능을 개선하는 과정을 함께 경험합니다.

혼자 도구를 익히는 데서 그치지 않고, 직접 실습하고 질문하며 서로의 경험을 나눠 보세요. 작은 개선을 반복하며 더 나은 에이전트를 만들어 갑니다.
