## 코드는 과감하게 실행은 신중하게

AI 코딩 에이전트는 코드 작성뿐 아니라 명령 실행도 수행합니다. 실습 환경을 어떻게 분리하고 어디까지 실행을 허용할지 함께 살펴봅니다.

GitHub Copilot, Docker, Azure 컨테이너 앱의 샌드박스를 활용하고 Docker 샌드박스 확장 기능을 직접 개발합니다. 내 개발 환경에 맞는 샌드박스 활용 방식을 찾아보세요.

## 이런 분들을 위한 행사입니다

### AI 코딩 에이전트를 더 안전하게 활용하고 싶은 분

에이전트의 코드 작성과 명령 실행을 실습하며 개발 환경과 실행 환경 사이의 경계를 이해하고 싶은 분께 추천합니다.

### 도구 사용을 넘어 직접 확장하고 싶은 분

GitHub Copilot을 활용해 Docker 샌드박스 확장 기능을 직접 개발해 보고 싶은 분을 환영합니다.

### 참가자 준비물 및 주의사항

- 실습에 사용할 개인 노트북과 GitHub 계정을 준비해 주세요.
- 실습에 사용할 Azure 구독은 각자 준비해 주세요.
- Azure 구독이 없다면 [무료 구독 만들기](https://aka.ms/azure/free)에서 가입 조건과 제공 범위를 확인해 주세요.
- Docker를 포함한 사전 설치 항목과 상세 실습 환경은 추후 안내합니다.
- Azure 리소스 및 모델 사용량에 따라 비용이 발생할 수 있습니다. 구독의 크레딧과 예산을 미리 확인해 주세요.
- 실습에는 민감한 데이터나 운영용 자격 증명을 사용하지 마세요.
- 실습 후 더 이상 필요하지 않은 Azure 리소스는 삭제해 주세요. 남겨 둔 리소스에는 추가 비용이 발생할 수 있습니다.
