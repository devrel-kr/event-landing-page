🕐 09:00 - 18:00

GitHub Copilot의 최신 기능을 활용해서 앱을 개발해 보고 싶은 개발자 및 비개발자를 대상으로 VS Code, Copilot CLI, GitHub App의 음성 코딩 기능만으로 애플리케이션을 개발하는 해커톤입니다.

🎯 이런 분들을 위한 행사입니다

🗣️

키보드 없이 코딩에 도전하고 싶은 분

손이 아닌 목소리로 애플리케이션을 만들어 보고 싶은 분. GitHub Copilot의 음성 코딩 기능을 직접 체험하며 새로운 개발 방식을 경험해 보세요.

👩‍💻

GitHub Copilot을 더 깊이 활용하고 싶은 개발자

VS Code, Copilot CLI, GitHub App을 음성으로 다루며 AI 보조 개발의 가능성을 한층 더 확장하고 싶은 개발자에게 적합합니다.

🚀

AI 코딩이 처음인 비개발자

코드를 한 줄도 써본 적 없어도 괜찮습니다. 말로 설명하면 Copilot이 앱을 만들어 주는 시대, 그 첫 경험을 함께해 보세요.
